# 🚀 TASKFLOW — Smart Task Management Dashboard

A modern and interactive task management application built with HTML5, CSS3, and JavaScript.

TASKFLOW helps users organize their daily tasks, manage priorities, track progress, and improve productivity through a clean, responsive, and intuitive dashboard.

---

## 🌟 Features

### 📋 Task Management
- Create new tasks with titles and descriptions.
- Edit existing tasks.
- Delete tasks.
- Assign priorities: High, Medium, and Low.
- Set task statuses.
- Set due dates for tasks.
- Organize tasks into categories.

### 🔍 Search & Filtering
- Search tasks by keywords.
- Filter tasks by status.
- Filter tasks by priority.
- Filter tasks by category.
- Sort tasks by due date.

### 📊 Dashboard & Productivity
- View total tasks.
- Track tasks currently in progress.
- Monitor completed tasks.
- Identify overdue tasks.
- View productivity statistics.
- Analyze task priorities.

### 🗂️ Kanban Board
- Organize tasks using a Kanban board.
- Move task cards between status columns.
- Use drag-and-drop to update task statuses.
- Switch between List and Board views.

### 🎨 User Interface
- Modern dark-themed dashboard.
- Clean and intuitive layout.
- Responsive design for different screen sizes.
- Interactive task cards and controls.

### 💾 Data Management
- Save tasks using browser LocalStorage.
- Preserve task data across page refreshes.
- Import and export task data in JSON format.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### 1. Clone the Repository

```bash
git clone https://github.com/mohamedelmallhy-prog/TASKFLOW.git
````

### 2. Open the Project

Navigate to the project directory:

```bash
cd TASKFLOW
```

### 3. Run the Application

Open the project in Visual Studio Code and run `index.html` using the Live Server extension.

You can also open `index.html` directly in your browser if the application does not require a local server.

---

## 📖 How to Use

1. Open the TASKFLOW dashboard.
2. Create a task using the Create Task button.
3. Enter the task title and description.
4. Select the task priority and status.
5. Choose a category and due date if needed.
6. Save the task.
7. Use the search bar and filters to find specific tasks.
8. Switch to Board view to organize tasks visually.
9. Drag and drop task cards between status columns.
10. Track your progress using the dashboard statistics.
